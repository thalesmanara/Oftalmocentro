# Manual Operacional — Oftalmocentro Inteligente

Guia prático para o dia a dia da clínica.

## 1. Login

1. Acesse o sistema pelo endereço informado pela equipe de TI.
2. Informe e-mail e senha.
3. Se a sessão expirar, a mensagem será: “Sua sessão expirou. Entre novamente.”

## 2. Dashboard

Visão rápida com:

- total de documentos;
- documentos ativos;
- em processamento;
- com falha;
- vigência expirada;
- atalhos para enviar documento e consultar a IA (conforme sua permissão).

## 3. Biblioteca de documentos

Em **Documentos** você pode:

- listar;
- buscar;
- filtrar;
- abrir o detalhe.

Só aparecem ações que a sua permissão permite.

## 4. Upload

Em **Upload** (quando permitido):

1. Preencha título, setor, categoria e demais campos.
2. Anexe o arquivo (PDF, imagem ou planilha, conforme regras).
3. Envie e acompanhe o processamento.

## 5. Tipos de arquivo

- PDF de texto
- PDF/imagem que precisem de OCR
- Planilhas (quando habilitadas)

Limite: **25 MB**. Arquivos com senha não são aceitos.

## 6. Status do documento

Mensagens em linguagem simples:

| Situação | Significado |
|----------|-------------|
| Processando | O sistema ainda está lendo o arquivo |
| Pronto / Válido | Disponível para consulta |
| Falhou | Precisa reprocessar ou suporte |
| Revisão | Precisa de revisão antes da consulta |
| Falha na indexação | Não ficou disponível para a Consulta IA |

## 7. Edição

Com permissão de editar, altere metadados ou substitua o arquivo quando necessário.

## 8. Versões

O detalhe do documento mostra o histórico de versões. Use a versão vigente para consultas.

## 9. Download

No detalhe ou nas fontes da Consulta IA, use **Download do arquivo**.

## 10. Consulta IA

1. Abra **Consulta IA**.
2. Digite a pergunta com clareza.
3. Aguarde a resposta.
4. Confira as **fontes consultadas**.

## 11. Fontes

A resposta deve citar documentos internos. Baixe o arquivo da fonte quando precisar conferir.

## 12. Avisos e limitações

A resposta pode vir com:

- aviso de divergência entre documentos;
- indicação de resposta parcial;
- pedido para esclarecer a pergunta (setor/categoria).

Leia o aviso antes de decidir.

## 13. Ausência documental

Se não houver documentação suficiente, o sistema informa que não localizou base interna segura. Não invente a resposta fora do sistema.

## 14. Permissões

Seu perfil pode incluir, por exemplo:

- visualizar / cadastrar / editar / excluir documentos;
- usar Consulta IA;
- cadastros administrativos (se for administrador).

Sem permissão, a área não aparece no menu ou exibe acesso negado.

## 15. Como solicitar suporte

Informe:

1. o que tentou fazer;
2. horário aproximado;
3. **código da solicitação** (quando a mensagem de erro mostrar);
4. print da tela, se possível.

## 16. Boas práticas

- Faça perguntas objetivas.
- Confira sempre as fontes.
- Mantenha documentos com vigência atualizada.
- Use títulos claros no upload.

## 17. O que não fazer

- Não tentar “burlar” a IA (ignorar instruções, pedir senhas ou chaves).
- Não enviar arquivos com senha.
- Não usar a Consulta IA para ações administrativas (apagar, executar comandos).
- Não compartilhar sua senha.
- Não colar CPF, prontuário ou dados sensíveis na pergunta sem necessidade operacional.
